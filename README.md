# Sngine 4.0.4海外社交平台PHP源码 – 多推广人支持短视频和博客订阅

源码地址：ym7k.com/17804/

Sngine 4.0.4 是面向海外市场打造的 PHP 社交平台源码，主打独立社区搭建，原生适配海外用户社交习惯，核心亮点包含多推广人分销体系、短视频信息流、博客付费订阅三大核心能力，同时整合社交互动、实时通讯、内容变现、多语言国际化等全套模块，适合搭建垂直海外社群、创作者社区、网红内容平台，依托 PHP 架构，部署灵活，配套完善后台管理能力，能够快速上线属于自己的海外社交站点。

短视频 Reels 模块是平台吸引流量的核心功能。创作者可以直接上传短视频内容，系统自动生成短视频信息流，支持上下滑动浏览、点赞、评论、收藏、转发分享，支持视频时长自定义配置。短视频支持独立设置可见权限，可选择公开可见、仅粉丝查看或者付费解锁观看。视频发布后自动推送至粉丝动态，搭配推荐分发机制，提升内容曝光。同时短视频和订阅体系打通，创作者可以将短视频内容纳入订阅专属内容，只有付费订阅用户才有权限观看，帮助短视频创作者稳定变现。

博客订阅功能为长内容创作者提供变现渠道。创作者可以发布图文博客文章，支持分类、标签管理，富文本编辑，支持插入图片、链接、素材，文章支持预览模式。平台提供订阅机制，用户可以选择订阅心仪博主，管理员以及创作者都可以自主设置订阅套餐、订阅周期和订阅价格。订阅成功后，用户解锁博主全部付费博客、专属动态、限定内容。订阅订单自动记录，收益按规则结算，创作者可以在个人中心查看订阅人数、收益明细，打造长图文内容的付费生态，适配资讯、测评、教程类海外创作者。

本次版本重点强化**多推广人支持**，搭建多人分销推广体系。区别于单一推广账号模式，系统支持添加多名推广人员，每个推广人拥有独立推广链接与推广素材。新用户通过推广链接注册、付费订阅、购买会员、打赏创作者时，对应推广人自动获得佣金。后台支持单独设置不同推广人的佣金比例，区分推广渠道，佣金明细独立统计，支持佣金提现管理。管理员可以查看各个推广人的引流数据、转化数据、佣金报表，方便招募海外本地推广、联盟渠道，依靠多推广人模式快速拉新，适合海外社媒联动引流运营。

基础社交功能完整成熟，包含用户主页、关注粉丝、动态发布、群组、粉丝专页。用户可以发布图文、状态、投票，支持好友添加、私信聊天、群聊，消息实时推送。隐私权限精细化控制，用户可以单独设置每一条内容的访问范围，适配海外用户对隐私的需求。平台自带多语言切换，支持 RTL 从右往左语言，适配多地区海外用户，同时内置广告系统，管理员投放全站广告，也允许创作者自助投放推广广告，提供多元变现途径。

支付与钱包体系适配海外主流支付渠道，内置平台钱包，支持用户充值、打赏创作者、支付订阅费、购买会员套餐。后台可配置多种付费方案，普通会员、高级会员权益分开，支持设置帖子付费解锁、私信付费、直播付费等多种付费模式，资金流水全部留痕，方便对账。

后台管控功能强大，管理员拥有全站管理权限，可管理用户、审核短视频和博客内容、封禁违规账号、配置风控规则、查看全站数据看板。系统统计新增用户、内容发布量、订阅订单、推广转化数据，可视化展示运营趋势。同时支持 PWA 移动端适配，手机浏览器访问体验接近 APP，无需上架应用商店即可让海外用户访问。

整套源码模块化设计，扩展性强，围绕创作者经济设计，短视频抓流量、博客做深度内容、多推广人做渠道裂变，三者相互配合，形成一套可自主运营、多渠道变现的海外社交社区方案，满足中小团队搭建垂直海外社交平台的需求。
